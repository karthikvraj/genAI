# Primary references

These implementations use established methods; no novelty claim is made.

- scikit-learn Isolation Forest: https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.IsolationForest.html
- scikit-learn TF-IDF vectorizer: https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html
- scikit-learn Random Forest regression: https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestRegressor.html
- SciPy two-sample KS test: https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ks_2samp.html
- SciPy Wasserstein distance: https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wasserstein_distance.html
- Ollama generation API: https://docs.ollama.com/api/generate
- GitHub CLI repository creation: https://cli.github.com/manual/gh_repo_create
- GitHub CLI release creation and asset upload: https://cli.github.com/manual/gh_release_create

Consult the installed library versions and their documentation before extending the examples. Rank-based anomaly calibration, Bayesian rankings and bootstrap intervals are reported with their assumptions in each project's README and JSON output.
